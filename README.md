## Our Process

### Built with

### What we learned

Thanks to this project, we were able to consolidate the concepts acquired during our training, namely :

- Use Figma to set up a prototype of the app
- Use Git / GitHub with a team (branch, pull requests, merge and (a lot of) conflicts)
- Implement logic concepts
- Use of @Bindings and @EnvironmentObject 
- Set up a true MVVM design pattern 

### Next steps

- Add a functionnal authentification system
- Set an NoSQL database 
- Continue to separate the views
